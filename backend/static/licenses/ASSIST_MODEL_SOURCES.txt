  Original model card (declares MIT, language English):
  https://huggingface.co/UsefulSensors/moonshine-tiny/tree/390624ed33d594443aa4aa221f5b9f283b545b5a

in THIRD_PARTY_NOTICES.txt. This bundle contains no Ultralytics object model.
